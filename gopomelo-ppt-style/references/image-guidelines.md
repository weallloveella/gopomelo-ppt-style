# Image and screenshot guidelines

## Selection

- Use original or highest-resolution assets available.
- Use each non-background image once by default.
- Select visuals that prove the current slide’s claim.
- Avoid generic stock photography when screenshots, product visuals, customer work, or event imagery are available.
- Do not reuse BytePlus demo media in unrelated GoPomelo decks merely because it exists in the landing-page project.

## Ratios

| Use | Ratio |
| --- | --- |
| Split visual | 16:10 or 4:3 |
| Case-study image | 16:9 or 3:2 |
| Mosaic group | one shared ratio across the group |
| UI/screenshot | 16:10 preferred |
| Full-page visual | 16:9 |

## Cropping

- Use `cover` for photography only when the subject remains intact.
- Use `contain` for UI, charts, diagrams, and text-heavy screenshots.
- Keep faces, products, labels, and data away from rounded crop corners.
- Do not crop in unrelated browser or console UI unless it is important evidence.
- For website previews, crop to the section that proves the slide's claim. If service cards are the evidence, show the cards rather than defaulting to the page hero.

## Screenshot treatment

- Preserve exact text and data when fidelity matters.
- Place screenshots on a warm neutral or soft gradient stage.
- Use one subtle shadow and one consistent corner radius.
- Do not redraw screenshots with generative tools unless the user explicitly requests a conceptual redesign.

## Slide-image export

- Use a 1280×720 CSS capture viewport at 3× device scale to export 3840×2160 images when they will be pasted into PowerPoint or Google Slides. Do not use a 3840×2160 CSS viewport.
- Use the HTML template's capture mode so navigation dots, keyboard hints, overview UI, and browser scrollbars are absent.
- Keep one image per slide and name the files in presentation order (`1.png`, `2.png`, …); use suffixes such as `5a.png` only when the visible page number requires them.
- Verify text edges and circular motifs at 100% zoom after upload; do not rely on a montage for pixel-quality review.

## Generated visuals

Ask before generating new imagery when user-supplied or local assets are sufficient. When generation is approved, match the final slot ratio and request a warm, premium, spacious visual without embedded slide titles or fake UI.
